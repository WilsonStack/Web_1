## 🛠️ Tecnologias e Conceitos Aplicados
* **Estruturação Semântica:** Uso de elementos do HTML5 (`<main>`, `<section>`, `<aside>`, `<nav>`, `<figure>`) para dar significado estrutural ao documento[cite: 2, 8, 10].
* **Hierarquia e Texto:** Organização de títulos (`<h1>`, `<h2>`), parágrafos e formatações inline (`<b>`, `<i>`)[cite: 1, 3, 4].
* **Listas e Menus:** Construção de listas ordenadas (`<ol>`) e não ordenadas (`<ul>`), aplicando atributos de personalização (`type`, `start`, `reversed`) e estruturas de navegação[cite: 5, 6, 7, 8].
* **Links e Âncoras:** Implementação de navegação interna utilizando identificadores (`id`) e links com a tag `<a>`[cite: 9].
* **Mídias e Figuras:** Inserção e dimensionamento de imagens (`<img>`) combinadas com elementos de legenda (`<figure>` e `<figcaption>`)[cite: 10, 11].
* **Tabelas:** Estruturação de dados organizados utilizando `<table>`, `<thead>`, `<tbody>`, `<tr>`, `<th>` e `<td>`[cite: 11].
* **Formulários:** Captura e envio de dados do usuário utilizando `<form>`, elementos `<input>` de múltiplos tipos, `<select>`, `<textarea>` e botões de ação[cite: 13].

## ⚠️ Limitações da Versão
* **Ausência de Estilização (CSS):** Os exercícios focam exclusivamente na estrutura markup nativa do HTML, sem folhas de estilo aplicadas.
* **Prototipagem Estática:** As páginas não possuem scripts de dinamismo (JavaScript) ou integração com back-end ativo.
