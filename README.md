# 🌐 Web I - Exercícios Práticos em HTML5

Este repositório contém os exercícios práticos desenvolvidos na disciplina/módulo de Desenvolvimento Web I (HTML5). O objetivo da coleção é exercitar os conceitos fundamentais de estruturação e semântica da web.

---

## 📁 Estrutura dos Exercícios

| Arquivo | Descrição / Tópicos Abordados |
| :--- | :--- |
| [`ativ1.html`](./ativ1.html) | **Estrutura Básica**: Criação da tag base HTML, parágrafos e elementos de rodapé (`<footer>`). |
| [`ativ2.html`](./ativ2.html) | **Semântica HTML5**: Utilização das tags estruturais `<main>`, `<section>` e `<aside>`. |
| [`ativ3.html`](./ativ3.html) | **Hierarquia de Títulos**: Organização de conteúdo com cabeçalhos (`<h1>` e `<h2>`). |
| [`ativ4.html`](./ativ4.html) | **Formatação de Texto**: Uso de formatação inline com `<i>` (*itálico*) e `<b>` (*negrito*). |
| [`ativ5.html`](./ativ5.html) | **Listas Ordenadas e Não Ordenadas**: Estruturação de listas simples com `<ol>` e `<ul>`. |
| [`ativ6.html`](./ativ6.html) | **Atributos de Listas Ordenadas**: Exploração de atributos como `type`, `start` e `reversed` em `<ol>`. |
| [`ativ7.html`](./ativ7.html) | **Estilização e Valores de Lista**: Prática de marcadores em listas não ordenadas e atributo `value` em listas ordenadas. |
| [`ativ8.html`](./ativ8.html) | **Navegação e Menus**: Criação de menus navegáveis com `<nav>` dentro de um bloco `<aside>`. |
| [`ativ9.html`](./ativ9.html) | **Links Internos (Âncoras)**: Navegação interna na página utilizando atributos `id` e links `<a href="#id">`. |
| [`ativ10.html`](./ativ10.html) | **Imagens**: Inserção de imagens com a tag `<img>` e uso dos atributos `src`, `alt`, `width` e `height`. |
| [`ativ11.html`](./ativ11.html) | **Figuras e Legendas**: Uso semântico de `<figure>` e `<figcaption>` para associar imagens a descrições. |
| [`ativ12.html`](./ativ12.html) | **Tabelas**: Construção de tabelas estruturadas com `<table>`, `<thead>`, `<tbody>`, `<tr>`, `<th>` e `<td>`. |
| [`ativ13.html`](./ativ13.html) | **Formulários**: Criação de formulários com `<form>`, campos de texto, e-mail, menu de seleção (`<select>`), área de texto (`<textarea>`) e botões. |
| [`ativ14.html`](./ativ14.html) | **Quebras de Linha e Comentários**: Uso da tag `<br>` e inclusão de comentários ocultos `<!-- -->`. |

---

## 🚀 Conceitos Estudados

- **Semântica Web**: Uso adequado de tags HTML5 para estruturação do documento (`main`, `section`, `aside`, `nav`, `figure`).
- **Navegação**: Links externos e âncoras para navegação na própria página (`href="#id"`).
- **Listas e Tabelas**: Organização de informações estruturadas em tabelas e múltiplos tipos de listas.
- **Mídia**: Incorporação e redimensionamento acessível de imagens (`alt`, `figcaption`).
- **Interatividade**: Captura de dados de usuário através de formulários nativos.
