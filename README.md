## 🛠️ Tecnologias e Conceitos Aplicados
* **Estruturação Semântica:** Uso de elementos do HTML5 (`<main>`, `<section>`, `<aside>`, `<nav>`, `<figure>`) para dar significado estrutural ao documento.
* **Hierarquia e Texto:** Organização de títulos (`<h1>`, `<h2>`), parágrafos e formatações inline (`<b>`, `<i>`).
* **Listas e Menus:** Construção de listas ordenadas (`<ol>`) e não ordenadas (`<ul>`), aplicando atributos de personalização (`type`, `start`, `reversed`) e estruturas de navegação.
* **Links e Âncoras:** Implementação de navegação interna utilizando identificadores (`id`) e links com a tag `<a>`.
* **Mídias e Figuras:** Inserção e dimensionamento de imagens (`<img>`) combinadas com elementos de legenda (`<figure>` e `<figcaption>`).
* **Tabelas:** Estruturação de dados organizados utilizando `<table>`, `<thead>`, `<tbody>`, `<tr>`, `<th>` e `<td>`.
* **Formulários:** Captura e envio de dados do usuário utilizando `<form>`, elementos `<input>` de múltiplos tipos, `<select>`, `<textarea>` e botões de ação.

## ⚠️ Limitações da Versão
* **Ausência de Estilização (CSS):** Os exercícios focam exclusivamente na estrutura markup nativa do HTML, sem folhas de estilo aplicadas.
* **Prototipagem Estática:** As páginas não possuem scripts de dinamismo (JavaScript) ou integração com back-end ativo.
